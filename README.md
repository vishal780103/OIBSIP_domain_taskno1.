
# NUMBER GUESSING GAME

A simple and interactive number guessing game built using Java. The program generates a random number, and the player must guess it within a limited number of attempts. It’s a great beginner-friendly project that demonstrates basic Java concepts like loops, conditionals, and user input handling.


## Features

Random number generation

User-friendly console interaction

Input validation

Attempts counter

Win/Loss result display


## HOW IT WORKS

The program generates a random number within a specific range (e.g., 1–100).

The player is prompted to enter a guess.

The program provides hints:

“Too high”

“Too low”

The game continues until the player guesses correctly or reaches the maximum number of attempts
## TECHNOLOGIES USED

Java

Scanner class for input

Basic control structures(loops, if-else, etc.)
## HOW TO RUN THE PROJECT

Install Java 

Write the code 

Open a terminal and navigate to the project folder.

Compile the Java file.

Run the program.
